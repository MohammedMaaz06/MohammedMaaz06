## Featured project · MCP Ops Assistant

When a cloud service raises an alert, the first engineering task is to understand what happened and who needs to know. For my final-year project, I built a multi-agent assistant around that workflow.

<img src="./assets/incident-flow.svg" width="100%" alt="A monitoring agent passes an alert to triage. The triage agent gathers context through MCP tools and passes its findings to notification.">

| Engineering decision | Why I chose it |
| --- | --- |
| Give monitoring, triage, and notification separate responsibilities | Each stage has a clear job, and I can inspect what one agent passes to the next. |
| Coordinate the workflow with LangGraph | The sequence of steps and the state carried between them are explicit in the code. |
| Connect operational tools through the Model Context Protocol | The triage agent can request the context it needs through a common interface. |

**Built with** · Python · FastAPI · LangGraph · Model Context Protocol
